1. Unduh Cadangan (Backup JSON)

Ekspor seluruh tabel transaksi, data pelanggan, konfigurasi harga, dan semua gambar foto pakaian ke dalam satu file .json.

File dapat disimpan di Google Drive, flashdisk, atau dikirim via WhatsApp antar kasir.

2. Backup Otomatis ke Folder Perangkat

Pilih folder di perangkat Anda sekali — selanjutnya backup JSON ditulis otomatis maksimal sekali per hari saat halaman ini dibuka.

Memeriksa folder backup...

Hanya tersedia di Chrome & Edge desktop (File System Access API). Browser lain tetap bisa menggunakan unduh manual di atas.

3. Pembersihan Foto Lama Otomatis

Hapus foto dari transaksi yang sudah diambil dan melewati batas umur foto (default 90 hari). Data teks transaksi dan pakaian tetap tersimpan.

Batas hari purge dapat diubah di menu Pengaturan → "Pembersihan Foto Otomatis".

4. Pulihkan Data (Restore JSON)

Pilih file cadangan .json yang pernah diunduh sebelumnya untuk mengembalikan atau memindahkan data ke perangkat ini.

Pilihan Pemulihan:
Browser akan memverifikasi struktur JSON sebelum data dimasukkan ke IndexedDB.
