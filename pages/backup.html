Backup & Restore Data IndexedDB Lokal

Amankan seluruh rekaman transaksi dan foto pakaian ke file JSON untuk dipindahkan antar perangkat.

Data Hanya Tersimpan di Perangkat Ini (Lokal Browser)

Aplikasi KIA Laundry berjalan 100% tanpa database server untuk kecepatan dan privasi maksimal. Menghapus cache atau riwayat peramban web dapat menghapus data jika belum di-backup. Disarankan untuk mengunduh Backup JSON secara rutin setiap tutup toko.

1. Unduh Cadangan (Backup JSON)

Ekspor seluruh tabel transaksi, data pelanggan, konfigurasi harga, dan semua gambar foto pakaian yang terkompresi ke dalam satu file berkas .json.

File dapat disimpan di Google Drive, flashdisk, atau dikirim via WhatsApp antar kasir.

2. Pulihkan Data (Restore JSON)

Pilih file cadangan .json yang pernah diunduh sebelumnya untuk mengembalikan atau memindahkan data ke perangkat ini.

Pilihan Pemulihan:
Browser akan memverifikasi struktur JSON sebelum data dimasukkan ke IndexedDB.
